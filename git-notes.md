## Day 2 - Lesson concept

Understanding how the git process work with the appropriate commands. Using git is a way to track the progress in a project by using 3 virtual places: the working directory, the staging area, and the registry of committments. The working directory is where the raw code is done, the staging area is wher you put your validated workor changes on the specific file, and the commit history is where you keep record the changes of that work done.

Understanding that git saves files and work on the .git directory on the local environment once actiona have been committed.
