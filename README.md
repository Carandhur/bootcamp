# 32-WEEK DEVELOPER WITH AI INTEGRATION BOOTCAMP

## PROJECT OVERVIEW

This repository serves as the workshop for the bootcamp. It keeps the exercises, assignments, working files, and student's personal notes.

## THE INSPECTION LOG

Practical exercise on how to get familiar with the Git environment.
Creating repos, adding and committing, then pushing them to the GitHub platform.

Objectives:

1. Creating the repository folder
2. Practising the core Git loop: init a repo, stage, and commit
3. Creating muscle memory for verifying processes
4. Managing local machine repo structure
5. Synchronising with online repos

STEPS:

```
mkdir inspection-log
git init
git status
git add inspection-log
git commit -m "Add inspection-log"
gh repo create bootcamp --public --source=. --remote=origin --push
```
